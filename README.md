# western-digital-wd1770

The Western Digital WD1770 floppy disk controller and its WD177x/179x relatives.

| Crate | Registry |
|---|---|
| [`emu198x-western-digital-wd1770`](crates/emu198x-western-digital-wd1770) | [crates.io](https://crates.io/crates/emu198x-western-digital-wd1770) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the BBC Micro, the Acorn Electron Plus 3, the Atari ST, the Commodore 1571 and 1581 drives and the Tatung Einstein.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
